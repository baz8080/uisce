### PR body

one candidate is the same update pasted twice).

is_open(row, now) now also refuses a passed observed end and a lift with
immediate effect. It is decided once in resolve_case and carried on
Case.is_open, so the open list, open_total, the national open view, the
county page's "Open now" section and notice text, the history's "still
open" and the Atom feed all read one answer. Scheduled ends still do not
close a case: a schedule is a plan, the same line the median draws. With
the clock pinned, every published figure is byte-identical under both
readings; only the open surfaces move (437 to 260 nationally).

The tests that built status="Open" on the default fixture, which carries a
completion, now use an _open() helper that is open by every reading; the
boil-notice fixture no longer carries an end no real boil notice has.

The deferral was the failure here, not the patch, so CLAUDE.md gets the
rule: a signal trusted for the arithmetic is trusted for the display, and
a trade-off left for the owner carries both sides' numbers. The
negative-span family's "no end reported" wording is recorded in the
roadmap as the adjacent inaccuracy this surfaced.
